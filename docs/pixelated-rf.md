# PixelatedRF — Inverse EM Design

End-to-end pipeline for designing RF patch antennas using a tandem neural network on the GF180MCU process.

## Quick Start — Web App

```bash
uv run uvicorn gelochip.pixelrf.app:app --host 0.0.0.0 --port 8001 --reload
```

Open [http://localhost:8001](http://localhost:8001):
1. Draw an S11 target curve with mouse/touch (or pick a preset notch)
2. Click **Run Inverse Design**
3. See the 12×12 pixel layout, surrogate S11 prediction, DRC results, and chip dimensions
4. Download the GDS file

Requires trained checkpoints in `notebooks/pixelatedRF/models/`. Run `02_train.ipynb` first.

## Models

### Forward Surrogate v4 — `ForwardSurrogateNet`

- **Architecture:** CoordConv + 3× SE-ResNet stages + multi-scale global average pooling + 6-block MLP head
- **Input:** 12×12 binary layout → **Output:** S11 at 81 freq points (1–10 GHz)
- **Params:** cnn_ch=48, hidden=512, n_res=3 (~10M params)
- **Loss:** depth-weighted MSE + 2× depth-weighted gradient + curvature
- **Result:** val MSE = 0.093 (z-scored) @ epoch 200

### Inverse Model v4 — `InverseNet`

- **Architecture:** cVAE with Straight-Through Estimator (STE)
- **Encoder** (training only): (S11 + flattened layout) → (μ, log σ²) in R^128
- **Decoder:** (z, S11) → layout logits via 3×3 seed → 6×6 → 12×12 CNN upsample
- **Inference:** z ~ N(0,1) only (encoder not used)
- **Params:** latent=128, hidden=512 (~4.1M params)

**Why v4 is better than previous versions:**

| Issue | v1 | v2 | v4 |
|-------|----|----|-----|
| Train/inference mismatch | Gumbel-STE ✓ | `fwd(sigmoid)` soft inputs ✗ | `fwd(STE binary)` ✓ |
| KL regularisation | Collapsed (free-bits=0.5, weight=0.1×) ✗ | None (no encoder) ✗ | Annealed 0→0.5, no free-bits ✓ |
| Tandem weight | 1× | 2× | **10×** |
| val_best8 (lower=better) | 0.301 | 0.589 | **~0.15** (projected @ epoch 150) |

**Key design decisions:**

- **STE:** forward pass uses `binary = (sigmoid > 0.5)` (same as inference), backward pass gradients flow through sigmoid. This means the tandem loss teaches the model *which specific pixel to turn on* to create a resonance at a given frequency, rather than "make the area denser".
- **KL annealing:** β ramps from 0 to 0.5 over 40 epochs. The encoder learns meaningful z representations before being regularised toward N(0,1), preventing posterior collapse.
- **Loss:** `10×tandem(STE) + 1×BCE + β×KL` — tandem dominant, BCE keeps encoder learning real layout structure.

## GDS Layout

The `03_layout_gds.ipynb` and `src/gelochip/pixelrf/gds_builder.py` build a GF180 MetalTop layout:

- **Pixel size:** 20 µm × 20 µm → 12×12 grid = 240 µm × 240 µm aperture
- **Layer:** MetalTop (46/0)
- **Boolean merge:** `gdstk.boolean(pixels, [], 'or')` merges edge-sharing pixels → eliminates same-net DRC spacing violations
- **RF feed pad:** 20×30 µm at center-bottom
- **Ground pads:** 4× 20×20 µm at corners
- **Ports:** `RF_IN` (orientation 270°), `RF_GND_BL/BR/TL/TR`

### DRC Rules (GF180 MetalTop)

| Rule | Value |
|------|-------|
| Min width | 0.36 µm |
| Min spacing | 0.36 µm |
| Min area | 0.5 µm² |
| Density | 5–80% |

Corner-touching pixels (diagonally adjacent, single-point contact) are classified as design-intent violations, not fabrication risk. To eliminate: use 19.64 µm pixels with 0.36 µm gap.

## FDTD Simulation (OpenEMS)

`04_simulate.ipynb` uses FR4 PCB substrate to match the PixelAnt dataset (generated by MATLAB Antenna Toolbox MoM on FR4):

| Parameter | Value |
|-----------|-------|
| Substrate | FR4 (εr=4.4, tanδ=0.02, h=1.6 mm) |
| Ground plane | Full PEC at bottom of FR4 |
| Patch | PEC, 35 µm thick (1oz Cu) |
| Pixel size | 700 µm × 700 µm (8.4 mm aperture) |
| Port | Lumped, 50 Ω, z-directed through FR4 only |
| Freq range | 1–10 GHz |

> **Note:** Earlier versions used the GF180 Si substrate (σ=10 S/m, 350 µm) which caused a flat −7.5 dB S11 with no resonance because the port spanned ~5 skin depths of lossy silicon at 5 GHz. FR4 is non-lossy in the port path → correct resonant coupling.

Install openEMS:
```bash
sudo apt install openems python3-openems
```
